# React Class Scheduler

A digital React Class Scheduler for Boutique Fitness Studio.

## Features

- Monochromatic corporate design system.
- Robust state management with `useState` and `useEffect`.
- Edge case handling (empty states, bad connectivity simulation, invalid inputs).
- Accessibility (a11y) support with 100% Lighthouse targets.
- Telemetry simulation.
- XSS sanitization using DOMPurify.

## Setup

1. Run `npm install`
2. Run `npm run dev`

## Architecture

- `src/components/`: Reusable UI components.
- `src/utils/`: Utility functions (sanitization, telemetry).
- `src/styles/`: (Directory created for future scalable styles if needed).
- `src/layouts/`: (Directory created for future layouts).
- `src/index.css`: Global design system variables and styles.
