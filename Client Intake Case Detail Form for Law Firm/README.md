# Client Intake & Case Detail Form

A robust multi-step React form application for a law firm.

## Features
- Multi-step client intake form (Client Details, Case Details).
- Custom Regex validation for email, phone, and required fields.
- Sanitizes all inputs against basic XSS injection.
- Simulates telemetry by logging to the console on completion.
- Graceful handling of bad connectivity (mock async submit with loading state).
- Strict monochromatic corporate design system with precise padding steps (16px, 32px).
- 100% Accessibility-focused (ARIA attributes, keyboard navigation).

## Setup
1. Run `npm install` to install dependencies.
2. Run `npm run dev` to start the development server.

## Tech Stack
- React
- Vite
- Vanilla CSS
